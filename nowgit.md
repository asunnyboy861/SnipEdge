## Repository Structure

```
SnipEdge/
├── SnipEdge/                      # iOS App Source Code
│   ├── App/                       # Entry point, app state, routing
│   ├── Design/                    # Theme tokens
│   ├── Models/                    # ChartReading, GradeCard, GradeRecord, Bar, Outcome
│   ├── Services/                  # Vision gate, OCR, market data, reconciliation,
│   │                              # confluence engine, AI clients, StoreKit, outcome tracker
│   ├── ViewModels/                # Analysis, Proof, BYO engine
│   ├── Views/                     # Home, Grade Card, Proof, Paywall, Settings,
│   │                              # BYO engine, Contact Support, Onboarding
│   ├── Assets.xcassets/           # App icon
│   └── PrivacyInfo.xcprivacy
├── SnipEdgeShare/                 # Share Extension target
├── SnipEdge.xcodeproj             # Generated by xcodegen
├── project.yml                    # xcodegen source of truth
├── docs/                          # Policy pages (GitHub Pages source)
├── us.md                          # English development specification
├── capabilities.md                # Capability configuration reference
├── icon.md                        # App icon documentation
├── price.md                       # Pricing and IAP configuration
├── app_review_info.md             # App Review notes
├── nowgit.md
├── GLMProxySecret.txt             # ⚠️ gitignored — local dev key only
├── keytext.md                     # ⚠️ gitignored — confidential ASO strategy
└── COMPETITOR_REPORT.md           # ⚠️ gitignored when generated
```

## Notes

- `GLMProxySecret.txt` is gitignored and excluded from Release builds via `EXCLUDED_SOURCE_FILE_NAMES`.
- `keytext*.md`, `COMPETITOR_REPORT.md`, and `app_audit*.md` never enter the repository.
- All AI user keys live in Keychain only; no secret is ever committed.
